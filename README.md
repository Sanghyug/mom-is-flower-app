토스 패키지 생성은 Vercel API 배포를 대신하지 않습니다.

기존 서버가 `VITE_OPENAI_API_KEY`만 썼다면 신규 API 배포 전에 서버 변수명을 변경해야 합니다.
`OPENAI_MODEL`은 선택 사항이며, 지정하지 않으면 기존 모델 `gpt-4o`를 사용합니다.

## 기존 기록과 저장 방식

기존 `mom-is-flower-archive`의 로컬 기록을 IndexedDB로 한 번 옮깁니다.
원본 localStorage는 보존하고, 이전이 완료된 뒤에는 삭제한 카드가 다시 나타나지 않도록 이전 완료 표시를 남깁니다.
저장 성공은 DB 트랜잭션 완료 후에만 표시합니다. 손상된 기록은 지우지 않고 오류를 안내합니다.
새 기록은 같은 꽃이라도 각각 저장하여 기존 사진을 덮어쓰지 않습니다.

이번 버전은 기기 내 저장을 기본으로 사용하며 Firebase 익명 로그인·자동 사진 업로드를 실행하지 않습니다.
기존 Firebase 서버 데이터는 삭제하지 않았습니다. 이전 앱도 서버 기록을 내려받는 기능은 없었으므로 서버 전용 기록의 복원 기능은 이번 범위에 포함하지 않았습니다.
기기·브라우저 또는 출처가 바뀌면 도감이 자동으로 동기화되지는 않습니다.

## 식물도감과 수집 레벨 (2026-10-29 추가)

앱 이름 엄마는꽃은 유지하며, 꽃과 나무·풀·관엽식물까지 식물도감으로 안내합니다.
기존 저장 키와 카드 형식, API 경로를 유지하여 저장한 기록을 그대로 사용합니다.
수집 레벨은 이름이 서로 다른 식물 수를 기준으로 0·10·30·60·100종에서 Lv.1~5가 됩니다.
같은 식물의 사진·메모는 각각 저장하되 수집 종류는 1종으로 셉니다. 추정 접두사와 공백 차이는 정규화합니다.
현재 저장한 도감 기준이므로 기록 삭제·복원 후 레벨과 진행도가 함께 계산됩니다.
사진 확인 후 서버 API를 통해 AI 분석을 요청하며, PC 웹에서는 카메라 대신 파일 선택창이 열릴 수 있습니다.
확장한 식물 인식 프롬프트는 로컬 소스에 반영했으며 실제 운영 반영에는 새 API 배포가 필요합니다.

## 돋보기·광고 보상 추가

최초 10개, 이름 찾기 1개, 토스 공유 완료 +2개, 보상형 광고 완료 +5개를 구현했습니다.
원래 레벨 이름을 복원했고, 추가 이야기의 가격은 미정으로 신규 요청을 잠갔습니다.
서버는 Firebase 익명 인증과 Admin Firestore 트랜잭션을 사용합니다. 식물 사진과 메모는 Firebase에 자동 업로드하지 않습니다.
현재 로컬 미리보기는 실제 AI·광고·공유를 실행하지 않는 명시적 체험 모드입니다.
실제 운영에는 서비스 계정·Firestore 규칙·광고 그룹 ID·공유 모듈 ID 설정과 기기 테스트가 필요합니다.
