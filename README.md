# 엄마는꽃

사진으로 꽃과 나무의 이름·꽃말·이야기를 알아보고, 메모를 더한 식물카드를 나만의 도감에 모으는 앱인토스 미니앱입니다. Flutter에서 시작한 앱을 웹·앱인토스로 재개발한 프로젝트의 2026-10-30 리뉴얼 최종본입니다.

- GitHub: https://github.com/Sanghyug/mom-is-flower-app

- 토스 콘솔: https://apps-in-toss.toss.im/workspace/44649/mini-app/mom-is-flower/app-build
- 리뉴얼 번들: `20261030-13`, Apps in Toss SDK `3.9.0`
- 운영자가 리뉴얼 버전 검토 요청을 완료했습니다. 정식 토스 출시는 검토 승인 이후 별도로 진행합니다.

## 주요 기능

- 카메라·앨범 사진으로 꽃·나무 등 식물 찾기. AI 분석 한 번으로 이름·꽃말·유래·관련 신화·설화를 함께 제공합니다. 확인하기 어려운 전승은 없다고 안내합니다.
- 사진·이름·꽃말·최초 생성 날짜·40자 메모로 QR 없는 JPEG 식물카드를 생성합니다.
- 개인 식물도감, 검색, 수집 종류별 레벨, 큰 글씨, 이야기 음성 읽기를 제공합니다. 기존 레벨 이름과 10·30·60·100종 기준을 유지합니다.
- 사용자가 선택한 카드만 30일 공개 링크로 공유합니다. 소유자는 링크 공유를 중단할 수 있으며, 전체 도감·계정 UID는 공개하지 않습니다.
- 공유 메시지에 ‘나만의 정원 만들기’와 토스 진입 링크를 포함합니다. 토스 파일 저장은 SDK의 OS 저장·내보내기 창을 사용합니다.
- 보상형 광고·배너 광고와 자체 친구 초대 링크를 연동합니다.

## 돋보기 정책

| 행동 | 지급·사용 | 한국 시간 하루 한도 |
| --- | --- | --- |
| 첫 지갑 연결 | +10 | 최초 1회 |
| AI 식물 찾기 | -1 | 50회, 별도 서버 전체 이용 한도 적용 |
| 보상형 광고 시청 완료 | +2 | 5회 |
| 식물카드 공유창 이용 | +1 | 3회 |
| 초대받은 새 계정의 첫 식물 찾기 성공 | 초대한 계정 +5 | 새 친구 3명 |

카드 공유 보상은 공유창 이용 기준이며 카카오톡 실제 전송·수신 확인은 아닙니다. 저장·링크 생성·링크 복사에는 지급하지 않습니다. 친구 초대는 단순 공유·접속이 아닌 서버의 첫 분석 성공 정산을 기준으로 지급합니다. 기존 지갑이 있는 계정·같은 계정의 자기 초대·중복 요청은 제외합니다. 익명 계정 기반이므로 실제 사람·기기의 동일성을 완전히 식별하는 방식은 아닙니다.

AI 호출 실패·식물 미발견 시 차감한 돋보기를 환급하고 동일 요청 재시도는 캐시로 처리합니다. 초대 보상은 한국 시간 하루 3명을 초과하면 이월 지급하지 않습니다.

## 개발과 빌드

Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run toss:build
```

- 일반 웹 빌드는 `dist/`, 토스 빌드는 `mom-is-flower.ait`를 생성합니다.
- 토스 SDK 설정은 `apps-in-toss.config.ts`입니다.
- 일반 Vite 개발 서버는 `api/` 함수를 실행하지 않습니다. Vercel 개발 환경을 사용하거나 `VITE_API_BASE_URL`을 API 서버 주소로 지정합니다.
- 웹 운영은 같은 출처의 `/api/`, 토스는 `.env.toss`의 운영 서버를 사용합니다.
- `VITE_WALLET_DEMO=true`는 개발 모드 전용 체험 기능이며 실제 AI·광고·공유 보상을 실행하지 않습니다.

## 서버 설정과 데이터

설정 항목은 `.env.example`을 참고하세요. OpenAI 비밀키는 서버 전용 `OPENAI_API_KEY`를 사용하며 `VITE_` 변수에 넣지 않습니다.

Firebase 서버 인증은 Vercel OIDC → Google Workload Identity를 사용하여 서비스 계정 비밀키 없이 연결합니다. `FIREBASE_SERVICE_ACCOUNT_JSON` 방식은 호환용 선택 사항입니다. Firestore REST 인증 호환성을 위해 `google-auth-library`는 `9.15.1`로 고정되어 있습니다.

지갑·광고 보상·카드 링크·초대 보상은 Firebase 익명 인증 및 서버 Firestore 트랜잭션으로 처리합니다. 새 개인 도감은 IndexedDB에 저장하며 기존 로컬 기록을 보존하여 이전합니다. 기기·브라우저·웹/토스 간 도감 자동 동기화는 제공하지 않습니다. 기존 Firebase `flower_cards` 데이터는 보존했고 소유자 접근 규칙을 적용했습니다. 사진·메모는 AI 분석 또는 사용자가 선택한 카드 링크 공유 외에 자동 업로드하지 않습니다.

기존 `contactsViral` 서비스는 토스의 2026-10-23 종료 공지에 따라 제거했습니다. 자체 `/invite/:code` 링크가 신규 지갑의 첫 성공과 초대한 계정을 연결합니다.
