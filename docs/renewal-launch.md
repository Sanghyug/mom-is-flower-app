# 엄마는꽃 리뉴얼 출시 메모

## 대상과 핵심 가치

사용자 가설은 '꽃과 산책에 관심이 있는 40~60대'입니다.
토스 전체 사용자의 연령 분포가 확인된 사실이라는 뜻은 아닙니다.
확인한 엄마는꽃 콘솔의 최근 대시보드는 집계가 0명으로 표시되어, 이 앱의 데이터만으로 연령 가설을 검증하기는 어렵습니다.

첫 이용의 목표는 꽃 하나의 이름을 알아내고 꽃도감에 담는 경험입니다.
이름·꽃말·이야기를 읽기 전에 공유를 요구하지 않습니다.
프로모션 리워드 참여 기능은 이번 코드에 임의로 추가하지 않았습니다.

## 소개 문구 초안

- 제목: 산책길에 만난 이 꽃, 이름이 뭘까요?
- 짧은 설명: 사진 한 장으로 꽃 이름과 꽃말을 알아보고, 나만의 꽃도감에 담아 보세요.
- 상세 소개: 길을 걷다가 마주친 예쁜 꽃. 엄마는꽃으로 사진을 찍거나 앨범에서 골라 보세요. AI가 이름과 꽃말을 찾아주고, 꽃에 담긴 이야기를 들려드려요. 그날의 마음을 짧게 적어 꽃카드로 간직하고, 소중한 사람과 나눠 보세요.
- 재방문 문구: 오늘 산책길에는 어떤 꽃이 피었을까요?

AI 결과를 식물도감의 확정 판별처럼 표현하거나 정확도를 수치로 보장하지 않습니다.

## 프로모션 이후 확인할 흐름

기존 Google Analytics 태그가 켜져 있을 때 다음 사건을 기록합니다. 사진·메모·꽃 이름은 분석 이벤트에 보내지 않습니다.

1. `flower_analyze_started`: 사진 확인 후 분석 시작
2. `flower_analyze_succeeded` / `flower_analyze_failed`: 분석 완료 또는 실패
3. `flower_story_opened`: 새 꽃 이야기 읽기 성공
4. `flower_card_saved`: 꽃도감 저장 완료

첫 분석 성공률, 성공 후 저장률, 다음 날 재방문을 먼저 봅니다.
외부 태그가 차단된 환경의 이벤트 누락과 반복 저장을 구분해서 해석해야 합니다.
토스 리워드 기능을 실제로 연동하지 않은 상태에서 금전 보상이나 지급 조건을 광고하지 않습니다.

## 실제 출시 전 순서

1. Vercel의 서버 전용 `OPENAI_API_KEY`와 현재 도메인 연결 확인
2. 새 웹·API를 미리보기 배포해 분석·꽃 이야기 실호출 확인
3. 생성된 `mom-is-flower.ait`를 토스 테스트 버전으로 등록
4. Android/iOS에서 카메라·앨범·취소·권한 거절·저장·공유·큰 글씨 확인
5. 기존 토스 도감 기록이 유지되는지 확인
6. 결과 확인 후 검토 요청·정식 출시, 이후 프로모션 설정

사업자 정보·예산·리워드·공개 출시는 이번 로컬 작업에서 변경하지 않았습니다.
