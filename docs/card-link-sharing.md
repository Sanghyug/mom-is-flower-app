# 식물카드 링크 공유

## 확인한 기존 코드

- `Sanghyug/mom-is-flower` 기본 브랜치는 Firebase 의존성이 없는 초기 로컬 저장 버전입니다.
- `Sanghyug/mom-is-flower-app`의 기존 버전은 Firebase 기본 앱에서 익명 인증하고 `flower_cards`에 카드를 저장합니다. 기존 이미지 공유는 Canvas → File → `navigator.share({files})` 경로였고 미지원 WebView에서는 중단됐습니다.
- 현재 리뉴얼 버전은 IndexedDB로 도감을 보관하고, Firebase 익명 인증은 서버 돋보기 인증에 사용합니다. 같은 프로젝트 ID라고 해서 다른 origin·앱 이름·기기의 익명 UID가 일치하는 것은 아닙니다. 기존 원격 카드의 자동 조회·UID 이전·전체 동기화는 이번 공유 구현에 포함하지 않습니다.

## 구현

공유 버튼 → 사진/메모 공개 범위 확인 → 카드 로컬 보관 → 인증된 POST `/api/share-card` → 선택한 카드의 독립 스냅샷 생성 → 링크 공유 버튼 → 토스 `share({message})` 또는 Web Share/주소 복사.

- 수신 링크 `/s/<256비트 난수 토큰>`는 로그인 없는 HTML 카드 페이지입니다. OG 이미지와 이미지 저장 링크를 제공합니다. 카카오톡 미리보기는 크롤러 환경·정책·캐시에 따라 달라지므로 실기기 검증이 필요합니다.
- Firestore 문서 ID에는 토큰의 SHA-256만 보관합니다. UID는 별도 서버 전용 소유자 컬렉션에만 저장합니다. 공개 응답에는 사진·이름·꽃말·메모·날짜만 포함합니다. 이미지 파일 공유를 토스 SDK가 직접 지원하게 된 것은 아닙니다.
- 링크는 30일 후 API에서 만료 처리합니다. 작성자만 공유를 해제할 수 있고 해제 시 공유용 이미지 복사본을 제거합니다. 원본 도감은 유지합니다. `no-store`/`noindex`를 사용하지만 이미 내려받거나 메신저가 캐시한 이미지까지 회수하지는 못합니다.
- 하루 UID당 생성 20회, 이미지 data URL 700,000자 이하. 새 AI 호출·돋보기 차감은 없습니다. 링크 생성/복사만으로 공유 보상을 지급하지 않습니다.
- Spark의 Firestore를 활용하며 Storage 버킷 생성, 요금제 업그레이드, 자동 유료 TTL 기능을 추가하지 않습니다. 만료는 접근 차단이며 DB 자동 삭제는 아닙니다. 운영 시 만료 문서를 정리해야 합니다.

## 활성화 전 필수 설정

1. 기존 Firestore 규칙 전체를 검토하여 아래 세 컬렉션이 클라이언트에 열려 있지 않은지 확인합니다. 광범위한 `allow read, write: if true` 등이 남아 있으면 개별 deny 규칙을 추가해도 보호되지 않습니다. 기존 `flower_cards` 데이터를 공개하는 방식으로 해결하지 않습니다.
   - `plant_shared_cards`: 서버만 읽기/쓰기
   - `plant_card_share_owners`: 서버만 읽기/쓰기
   - `plant_card_share_limits`: 서버만 읽기/쓰기
2. 이미 도입한 서버용 `FIREBASE_SERVICE_ACCOUNT_JSON`을 안전하게 설정합니다. 브라우저 공개 Firebase 설정만으로 Admin API가 작동하지 않습니다. 개인 키를 Git/클라이언트/채팅에 넣지 않습니다.
3. 서버 `PUBLIC_APP_ORIGIN`을 실제 HTTPS Vercel 도메인으로 지정합니다.
4. 규칙 확인이 끝난 배포에서만 서버 `CARD_SHARING_ENABLED=true`로 설정합니다. 기본값은 비활성화입니다. 로컬 체험 모드는 사진을 업로드하거나 공개 링크를 만들지 않습니다.
5. 두 기기로 생성·열람·이미지 저장·만료/해제·타 UID 해제 거부를 검증합니다. 토스에서 카카오톡으로 링크를 보내 수신 화면까지 확인합니다.

실제 서버 자격 증명·규칙 설정·실서비스 배포가 끝나지 않으면 기능이 준비 중으로 안내됩니다. 기존 데이터나 운영 접근 규칙을 코드만으로 변경하지 않습니다.

## 운영 콘솔 확인 (2026-10-30)
현재 규칙은 모든 문서에 request.time < timestamp.date(2026, 7, 21)만 허용하는 만료된 테스트 규칙입니다. 따라서 현재 클라이언트 DB 읽기/쓰기는 차단됩니다. 익명 인증 성공과 DB 저장 성공은 별개입니다. 서버 Admin SDK는 이 규칙과 별개로 서버 자격 증명이 필요합니다. 관찰한 규칙과 소유자 전용 교체 제안은 같은 docs 폴더의 .rules 파일로 보관했으며 배포하지 않았습니다. 현재 공유 서버 컬렉션은 클라이언트 접근이 차단되는 규칙이므로, 새 공유 기능을 위해 DB 전체를 공개할 필요가 없습니다.

## 앱인토스 진입 링크
새 카드 이미지 하단에는 앱 이름·HTTPS 진입 주소와 QR을 넣습니다. 이미지의 글자는 클릭되지 않으므로 QR을 사용합니다. 공유 메시지에는 카드 보기 링크와 앱 진입 링크를 함께 넣고, 수신 페이지에도 토스에서 엄마는꽃 열기를 표시합니다. 토스 실행 환경에서는 getTossShareLink(intoss://mom-is-flower)로 공식 공유 링크를 생성합니다. 일반 웹/QR의 고정 주소 /toss는 서버 TOSS_APP_SHARE_URL이 설정되면 해당 공식 HTTPS 주소로 이동하고, 미설정이면 사용자가 눌러 여는 intoss 딥링크 안내 페이지를 제공합니다. 기존 저장 카드 이미지 원본은 다시 그리거나 덮어쓰지 않습니다. QR의 /toss 경로는 신규 배포 후에 사용 가능합니다.
